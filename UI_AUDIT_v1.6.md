# WARSTATE v1.6.0 UI audit

## Реально изменено

- Нижняя навигация: 6 основных разделов вместо 7 сжатых пунктов.
- Стратегический штаб перенесён в раздел «Остров» отдельной кнопкой, функциональность сохранена.
- Закрытие карточки острова использует симметричный SVG-крест из двух линий вместо шрифтового `×`.
- Внешняя оболочка Mini App прозрачная, без искусственной рамки и тени устройства.
- Telegram WebApp header/background/bottom bar синхронизируются с цветом приложения через optional SDK methods.
- Header, stat chips, island labels, map controls, selected-island sheet и bottom nav переработаны в единый полупрозрачный sea-glass стиль.
- Внутренние экраны получили единый пляжно-морской фон, облегчённые карточки, рамки и тени.
- Пользовательский брендинг приведён к WARSTATE.

## Проверки

- TypeScript/TSX синтаксический transpile: 56/56 файлов.
- Локальные `@/` импорты: отсутствующих нет.
- CSS: баланс фигурных скобок корректный.
- В архив не включаются `.env`, `.git`, `.next`, `node_modules`, `.vercel`.
- Полный `npm run build` в контейнере не подтверждён: `npm install` не завершился из-за сетевого таймаута registry.

## Ограничение Telegram

Верхний системный крестик и меню самого Telegram Mini App рисует клиент Telegram, а не React-приложение. Код проекта не может изменить геометрию этого системного крестика. В v1.6 цвет нативного chrome синхронизируется с приложением, чтобы внешняя рамка визуально сливалась с интерфейсом. Крестик внутри игрового интерфейса исправлен полностью.
